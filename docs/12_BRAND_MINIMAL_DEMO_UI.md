# RAHHAL AI brand — only for standalone demo console

This is NOT the earlier tourism website identity implementation; the full website remains postponed.

- Working brand: **RAHHAL AI / رحّال AI**; fictional travel company for university demonstration, explicitly indicated.
- Brand voice: personable, concise, Egyptian Arabic, thoughtful, not deceptive about being AI.
- Primary palette: Navy `#102A43` (trust), Teal `#0D9488` (actions/tool state), Champagne Gold `#D6B37A` (small accent), Warm Ivory `#F8F7F3` (light background), Coral `#F47764` (rare notification accent).
- Font recommendation when available: **Tajawal** for Arabic body, **Alexandria** for Arabic headings, **Inter** for Latin UI; use reliable Arabic-capable system fallback if external fonts are unavailable.
- Core surface: compact single-screen text/voice conversation and optional trace sidebar. No photography, travel destination gallery, landing page, videos or marketing animations.
- Accessibility: Arabic RTL/English LTR, readable contrast, voice record/upload and retry indicator, clear “DEMO DATA” and “UNVERIFIED EXTERNAL LISTING” labels, responsive mobile.
- Motion only for conversational microinteractions: brief new-message transitions, recording-state indicator and accessible loading, respecting reduced motion. Do NOT activate film/video skills to build a marketing hero.
